# Café Origen - Motor de Analítica de Ventas

## Descripción

Café Origen es un proyecto desarrollado en JavaScript y Node.js
que permite analizar el historial de ventas de una empresa
comercializadora de café y accesorios.

El proyecto procesa los registros de ventas y genera indicadores
que facilitan la interpretación del comportamiento comercial
del negocio.

## Tecnologías utilizadas

- JavaScript
- Node.js
- Git
- GitHub
